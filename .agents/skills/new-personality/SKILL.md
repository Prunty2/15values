# Add a researched personality

Read the repository's [AGENTS.md](../../../AGENTS.md),
[contributor guide](../../../CONTRIBUTING.md), and shared
[profile procedure](<../../../docs/personality assessments/NEW_PROFILE.md>), including its linked
tool reference. Paths in commands are relative to the repository root unless the
procedure says to work in `frontend/`.

Catalogue argument: `personality`. The input is the user's named subject or existing ID.
Check for an existing entry and draft before creating an ID. Do not populate any unrequested subjects.

Define the public figure and period. Verify dated positions and actions, including changes and contradictions. Find an authentic portrait on Wikimedia Commons, following Andy Burnham's existing image. Record its Commons File page, creator and licence, and add its reference to the footer-linked Image credits list as required by the shared procedure.

Carry the authorised profile through research, all 240 evidence-backed answers,
separate review, validation, immutable archive, generation and browser checks.
Use the project's existing scorer. Unknown evidence stays unresolved; do not
substitute Neutral, copy another profile, or tune answers to avoid similarity.
Record the actual review and verification. If research remains insufficient,
keep a draft and explain the specific gap. Prepare a scoped contribution; open a
PR only when requested, and never auto-merge or deploy.
